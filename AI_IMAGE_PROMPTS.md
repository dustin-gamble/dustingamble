# AI Image Prompts And Naming Guide

Use this file to generate optional AI-rendered images for writing and project pages.

## How the site loads images

- The site auto-loads images only if files exist.
- No placeholders are rendered when files are missing.
- Supported formats: `.webp`, `.png`, `.jpg`, `.jpeg`.
- Recommended format: `.webp`.

## Naming convention

- Writing pages: `public/images/writing/<slug>-1.webp`, `public/images/writing/<slug>-2.webp`.
- Project pages: `public/images/projects/<slug>-1.webp`, `public/images/projects/<slug>-2.webp`.
- Optional extras: add `-3` and `-4` with the same pattern.

Example:

- `public/images/writing/ai-wont-replace-engineers-but-it-will-change-how-we-build-1.webp`
- `public/images/projects/world-record-endurance-flight-stalker-vxe-2.webp`

## Optional images 3 and 4

If you generate more images for a page, continue numbering:

- `...-3.webp`
- `...-4.webp`

The page templates automatically render any existing files from `-1` through `-4`.
